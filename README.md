# IEOstats

R package for analysing complex survey data. The IEOstats package contains 
functions to estimate totals, variances and confidence intervals from complex 
survey samples.

## Installation

The development version of the package can be installed from GitHub using the
`pak` package:

```r
# install.packages("pak")
pak::pak("joel-ieo/IEOstats")
```

## Features

- Complex survey data analysis.
- Variance estimation: Horvitz-Thompson or multistage rescaled bootstrap
approach.
